## Featured work

### Student Debt Payoff Prediction

**[ML_DS4400_Project](https://github.com/Eeeeqyq/ML_DS4400_Project) · [Try the demo](https://demo-theta-orcin-89.vercel.app/)**

Led a Northeastern group project estimating institution-level student debt payoff time from U.S. College Scorecard data covering **6,300+ institutions**.

- Engineered a repayment-time target and excluded its inputs from model features to prevent leakage.
- Compared Ridge, Decision Tree, Random Forest, and PyTorch models; best results reached **MAE ≈ 3.95 years** and **R² ≈ 0.63**.
- Produced 20+ visualizations and a browser-based interactive demo.

*Python · pandas · scikit-learn · PyTorch · Vercel*
